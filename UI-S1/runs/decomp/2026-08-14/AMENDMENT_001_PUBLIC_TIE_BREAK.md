# Amendment 001: Arm 2 public tie-break

Date: 2026-08-15

Status: `FROZEN_BEFORE_DECOMP_PREFLIGHT_OR_ANY_ARM_RESULT`

The frozen public ScreenSpot-Pro C-uni schema contains `action`, `coordinate`, `parameter`, and `parse_ok` for each candidate, but does not contain candidate coverage. Arm 2 is prohibited from opening non-public fields.

Therefore Arm 2 mode-class ties and within-class representative ties use the earliest canonical candidate index only. The fixed 14-pixel complete-link geometry and `[7,14,28]` sensitivity grid are unchanged. Arm 1 retains canonical density B3 coverage tie-breaking because it is label-dependent and operates on the complete frozen evaluation bank.

No DECOMP preflight, Q1, Q2, or other arm result existed when this amendment was written.
